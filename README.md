# Hide Pause Window

Jump Kingのmodです。ポーズ中に設定したボタンを押すと、ポーズ画面のウィンドウ（ステータス枠・メインメニュー枠・Objective欄など）をすべて非表示にし、フリーズした背景のゲーム画面をそのまま見ることができます。もう一度同じボタンを押すと元のポーズ画面に戻ります。

## やりたいこと（確定仕様）

- ポーズ中、ユーザーが設定した1つのボタン（キーボード・コントローラー両対応）を押すと、ポーズ画面の描画だけが消え、背景（フリーズしたゲーム画面）がそのまま見える
- ポーズ状態（ゲームの一時停止）自体は維持される。背景は静止画のまま、ウィンドウだけが消える
- ウィンドウが非表示の間は、上下キー・確認・キャンセルなどのメニュー操作をすべて無効化する（誤ってメニューのカーソルが動いたり、見えない状態で「Give Up」等を確定してしまう事故を防ぐため）。再度同じボタンを押してウィンドウを再表示すれば、通常の操作に戻る
- ボタンの設定は、ポーズメニュー内に「ボタンを押して登録する」専用UIを用意する（[Save States](https://steamcommunity.com/sharedfiles/filedetails/?id=3161216998) mod の Bind Keys 画面と同様のUX）

## 技術的な実現方針（概要）

- `JumpKing.PauseMenu.PauseManager.Draw()`をHarmonyでパッチし、非表示フラグが立っている間は描画自体をスキップする（ゲーム側に暗転オーバーレイ等は存在しないため、これだけで背景全体がそのまま見える見た目になる）
- `JumpKing.PauseMenu.PauseManager.PauseUpdate()`をHarmonyでパッチし、毎フレーム独自のボタン押下を検出（ゲーム本体のボタン体系には空きスロットが無いため、mod独自にキー/ボタンを保持・判定する）。非表示中は`ControllerManager.instance.MenuController.ConsumePadPresses()`でメニュー入力を握りつぶす
- キー登録UIは、ゲーム本体が内蔵する`BindButtonFrame`等のコントロール割り当て部品を、SaveStatesと同じ手法で流用する

詳しい調査経緯・各クラスの実装根拠は[NOTES.md](NOTES.md)を参照してください。

## 必須環境（予定）

既存mod群と同様、Harmonyを使用しますが`0Harmony.dll`を同梱予定のため、別途サブスクライブする必要はありません。
